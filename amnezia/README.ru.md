# AmneziaWG 3.1 в KeeneticOS

[English](README.en.md) · [Вариант через Entware](ENTWARE.ru.md)

AmneziaWG 3.1 поддерживается штатно начиная с KeeneticOS 5.2 Alpha 11. Для [списка совместимых моделей и полного руководства](https://docs.amnezia.org/ru/documentation/instructions/keenetic-os-awg/) откройте документацию Amnezia. В списке есть Keenetic Giga KN-1012 и Netcraze Giga NC-1012. Подключение создаётся в веб-интерфейсе роутера, Entware для него не нужен.

Версия 5.2 Alpha 11 доступна через канал разработчика. Такая прошивка может работать менее стабильно, чем ваша текущая. Если роутер уже работает на подходящей версии, переходите к установке компонента. На более старой версии сначала решите, готовы ли вы обновлять прошивку. [Сборка для Entware](ENTWARE.ru.md) проверена автором только на конкретном NC-1012 с прошивкой 5.1.5; считать её универсальной заменой обновлению нельзя.

## Подготовка

1. Проверьте модель и версию KeeneticOS в веб-интерфейсе.
2. Скачайте из настроек системы два файла резервной копии: `firmware` и `startup-config`. В новых версиях они находятся на вкладке «Файлы».
3. Если переходите на канал разработчика, посмотрите [известные проблемы текущей сборки](https://forum.keenetic.ru/) и отключите автоматическое обновление, чтобы следующий выпуск не установился без вашего участия.
4. Для Amnezia Premium получите клиентский `.conf` в личном кабинете. Для Self-hosted откройте AmneziaVPN, поделитесь отдельным подключением AmneziaWG для роутера и выберите «Оригинальный формат AmneziaWG». Полный ключ `vpn://…` и файл `.vpn` для штатного импорта не подходят. Не публикуйте `.conf`: в нём находится приватный ключ.

## Создайте подключение

1. В «Настройки системы» откройте «Изменить набор компонентов», найдите WireGuard VPN и установите его через «Обновить NDMS». Дождитесь окончания установки и возможной перезагрузки.
2. В разделе «Интернет» откройте «Другие подключения», нажмите «Загрузить из файла» и выберите клиентский `.conf`.
3. Включите «Использовать для выхода в интернет», сохраните подключение и переведите его переключатель в положение «Включено».

Для первого теста оставьте обычное подключение к провайдеру выше WireGuard в политике по умолчанию. Создайте отдельную политику с WireGuard, назначьте ей одно устройство и проверьте на нём внешний IP и доступ к сайтам. Если в этой политике оставить только WireGuard, при обрыве VPN устройство останется без интернета. Добавленный вторым провайдер даст запасной путь, но трафик сможет идти напрямую при сбое VPN. Когда проверка пройдёт, назначьте остальные устройства.

## DNS и IPv6

В [первом шаге руководства Amnezia](https://docs.amnezia.org/ru/documentation/instructions/keenetic-os-awg/#шаг-1-настройка-dns) предлагается добавить публичные DNS-серверы, при желании игнорировать DNS провайдера и отключить IPv6 на основном подключении. Это меняет настройки всей домашней сети. Для первого теста отдельного устройства начните с подключения и политики выше; затем настройте DNS и IPv6 под выбранную схему маршрутизации.

Если хотите направлять трафик по доменам, следуйте разделу «Маршруты DNS» в документации Amnezia. Устройства должны использовать DNS роутера: пользовательский DNS, Private DNS или DNS-over-HTTPS в браузере обойдут эти правила. Если VPN переносит только IPv4, оставленный на основном подключении IPv6 может идти напрямую. Проверьте обе версии IP перед массовым переключением устройств.

После настройки сохраните конфигурацию роутера и повторите проверку после перезагрузки.
